# poker-calculator

A basic Python program that calculates the probabilities of different poker hands throughout a game of Texas Hold'em

## Features
Supports single, multiple, and infinite decks
Updates probabilities after the hole cards, flop, turn, and river
Calculates 11 categories of poker hands
Includes input validation and detection of duplicate cards
Uses a combination of exact probability calculations and Monte Carlo simulations

## How to Use
Run `poker_odds_calculator.py` in any Python 3 environment, no external libraries required
